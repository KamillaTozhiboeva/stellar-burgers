# Stellar Burgers

## Описание проекта
**Stellar Burgers** — это интерактивное SPA-приложение космической бургерной. Проект представляет собой полноценный клиентский интерфейс, где пользователи могут собирать бургеры из различных ингредиентов, просматривать детальную информацию о каждом компоненте, оформлять заказы и отслеживать их статус в ленте через WebSockets. 

В проекте реализована система авторизации и регистрации пользователей, защищенные маршруты (Private Routes) и управление сложным глобальным состоянием.

## Стек технологий
- **Язык:** TypeScript
- **Библиотеки:** React, React Router v6
- **Стейт-менеджмент:** Redux (Redux Toolkit)
- **Взаимодействие с API:** REST API, WebSockets
- **UI/UX:** Dnd-core (Drag-and-Drop)

## Инструкция по развёртыванию

Для того чтобы запустить проект локально на вашем компьютере, выполните следующие шаги:

1. Клонируйте репозиторий:
```bash
git clone https://github.com/KamillaTozhiboeva/stellar-burgers.git
```

2. Перейдите в папку проекта:
```bash
cd stellar-burgers
```

3. Установите зависимости:
```bash
npm install
```

4. Настройка окружения:
```env
Создайте файл .env в корневой папке проекта и добавьте в него ссылку на API:
BURGER_API_URL=https://norma.education-services.ru/api
```

5. Запустите проект в режиме разработки:
```bash
npm start
```

После этого приложение будет доступно в браузере по адресу: http://localhost:4000/
